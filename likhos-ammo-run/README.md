# Likho's Ammo Run

Makes 4.6x30 and 9x39 available from Gunsmith. Reworks "Ammo Delivery" task.

## Features

The idea is to make high-end ammo actually usable in game instead of being an exotic safe queen.

Gunsmith now sells 4.6x30, 9x39 and 7.62x54R ammo, plus VSS and MP7 magazines. 

The "Ammo Delivery" task reworked:

| | Vanilla | Modded |
|---|---|---|
| Deliver | 1 box of 4.6x30, 9x39 and 7.62x54R | 10 boxes of 7.62x39 and .223 |
| Reward | LVPC (Winter) rig and Armor Plate (IV) | 3 boxes of 4.6x30 and 9x39 |

Note that trader's supply is generated at random from a large pool of items, so a given caliber may not always be there.

## Requirements

- Road to Vostok 0.2.0.0 (Godot 4.6.3)
- [Metro Mod Loader (MML)](https://vostokmods.net/mod/metro-mod-loader) v3.4.1 or later
