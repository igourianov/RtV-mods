# Likho's Radiola - HardBOSS Radio

A station pack for [Likho's Radiola](https://modworkshop.net/search/mods?query=%22Likho%27s%22&sort=likes). Adds the **HardBOSS Radio** station to the shelter radio.

Requires the **Likho's Radiola** core mod. On its own this pack does nothing; install the core and the station appears in the radio's tuning cycle.
