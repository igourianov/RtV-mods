# Likho's Magdump

Road to Vostok mod that allows for using cross-compatible magazines as they should be in real life.

Following guns can now use each other's magazines:
* AK-74SU <-> AK-12
* AKM <-> RK variants
* KAR-21 (.223 version) <-> STANAG pattern rifles
