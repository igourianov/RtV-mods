# Likho's Magdump

Cross-compatible magazines as they should be in real life.

## Features

Following guns can now use each other's magazines:
* AK-74SU <-> AK-12
* AKM <-> RK variants
* KAR-21 (.223 version) <-> STANAG pattern rifles

## Requirements

- Road to Vostok 0.2.0.0 (Godot 4.6.3)
- [Metro Mod Loader (MML)](https://vostokmods.net/mod/metro-mod-loader) v3.4.1 or later
