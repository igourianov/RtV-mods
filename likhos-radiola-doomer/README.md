# Likho's Radiola - Doomer

A station pack for [Likho's Radiola](https://modworkshop.net/search/mods?query=%22Likho%27s%22&sort=likes). Adds the **Doomer** station: melancholic background music for the shelter radio.

Requires the **Likho's Radiola** core mod. On its own this pack does nothing; install the core and the station appears in the radio's tuning cycle.

Track source: https://www.youtube.com/watch?v=cO1o37Dyc8A
