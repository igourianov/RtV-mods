# Likho's Second Hand

Road to Vostok mod that lets a few compact long guns ride in the secondary slot, and trims their inventory footprint to match.

Affected weapons:
* AKs-74U
* VSS Vintorez
* Remington 870
* KP-31

Each of these now fits in either the primary or secondary slot, with their inventory size reduced by one cell along the long axis. (KP-31 was already secondary-eligible in vanilla; this mod just shrinks its footprint.)
